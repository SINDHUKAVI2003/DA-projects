# House Price Trend Modelling

## Project Overview

This project focuses on analyzing the factors that influence residential property prices and developing a predictive model to estimate house prices based on key housing and neighborhood characteristics. The analysis was performed using statistical techniques, correlation analysis, and regression modelling to identify the most significant variables affecting house values.

## Objective

The primary objectives of this project are:

* Analyze housing data to understand price-driving factors.
* Identify relationships between independent variables and house prices.
* Build a regression model for house price prediction.
* Evaluate the strength and accuracy of the predictive model.
* Generate actionable insights from the housing market data.

## Dataset Information

The dataset contains **506 housing records** with the following variables:

| Variable   | Description                             |
| ---------- | --------------------------------------- |
| CRIME_RATE | Crime rate in the area                  |
| AGE        | Age of residential properties           |
| INDUS      | Proportion of non-retail business acres |
| NOX        | Nitric oxide concentration              |
| DISTANCE   | Distance to employment centers          |
| TAX        | Property tax rate                       |
| PTRATIO    | Pupil-teacher ratio                     |
| AVG_ROOM   | Average number of rooms per dwelling    |
| LSTAT      | Percentage of lower-status population   |
| AVG_PRICE  | Average house price (Target Variable)   |

## Project Workflow

### 1. Exploratory Data Analysis (EDA)

* Examined descriptive statistics.
* Analyzed variable distributions using histograms.
* Identified trends and patterns in housing attributes.

### 2. Relationship Analysis

* Calculated covariance between variables.
* Performed correlation analysis to measure relationships.
* Visualized key relationships using scatter plots.

### 3. Regression Modelling

* Developed regression models to predict house prices.
* Evaluated the impact of independent variables on property values.
* Selected the best-performing model based on statistical significance and predictive performance.

## Key Findings

* **AVG_ROOM** showed a positive relationship with house prices.
* **LSTAT** demonstrated a strong negative relationship with house prices.
* Areas with lower crime rates and better living conditions generally exhibited higher property values.
* Multiple housing and neighborhood characteristics collectively influence property prices.
