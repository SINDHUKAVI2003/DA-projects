# Google Play Store Analysis

## Project Overview
Analyzed Google Play Store app data to identify trends in ratings, installs, reviews, and categories.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Key Insights
- Gaming apps generated the highest installs
- Productivity apps maintained higher ratings
- Free apps dominated overall downloads

- notebook.ipynb
- dataset.csv
