# 📂 Projects Included

## 1. Google Play Store App Analysis (Python)

**Objective:**
Analyze Google Play Store application data to identify trends, patterns, and factors influencing app performance.

**Key Activities:**

* Performed data cleaning and preprocessing
* Handled missing values and duplicate records
* Conducted exploratory data analysis (EDA)
* Analyzed app ratings, categories, reviews, and installs
* Created visualizations to identify patterns and insights

**Tools Used:**
Python, Pandas, NumPy, Matplotlib, Seaborn

---

## 2. Sample Superstore Sales Dashboard (Tableau)

**Objective:**
Develop an interactive sales performance dashboard to analyze business performance and identify key areas for improvement.

**Key Activities:**

* Created interactive Tableau dashboards
* Analyzed sales, profit, and customer performance
* Identified top-performing and loss-making products
* Used filters, KPIs, and visualizations for business insights
* Performed regional and category-level analysis

**Tools Used:**
Tableau

---

## 3. Travego Bus Reservation System Analysis (SQL)

**Objective:**
Design and analyze a bus reservation database to understand customer bookings, revenue trends, and operational performance.

**Key Activities:**

* Designed relational database tables
* Performed SQL queries for data analysis
* Used joins and aggregations to combine and analyze data
* Applied advanced SQL concepts including CTEs and window functions
* Generated insights from booking and customer data

**Tools Used:**
MySQL
